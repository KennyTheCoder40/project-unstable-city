# Title: Unstable City

## Repository

## Description
Unstable City will be an interactive artwork that allows the user explore a pixelated city.
The artwork will be aesthetically pleasing and implement basic movement for user engagement.

## Features
- Feature 1: Press ARROW keys to move background position.
	- Get pressed keys, then update Vector position based on ARROW direction.
- Feature 2: Character has a walking animation when moving.
	- Create a list containing all images in animation.
  	- Utilize a while loop to iterate through list while user holds ARROWS.
  	- Loop breaks when player lets go of ARROWS.
- Feature 3: SHIFT keys to switch background & character costume.
	- Get pressed keys to introduce SHIFT keys.
 	- If/elif statement may be necessary to swap between visuals.
 	- Custom functions are needed to simplify the code.

## Challenges
- Since display window will be condensed, the background needs to move with the character.
- I need to find a function that allows code to execute when user **holds** keys.
- I want the list to keep looping itself until the user stops holding the ARROWS.

## Outcomes
Ideal Outcome:
- Ideally, the user switches between two images of the city and character. One image portrays them normally, but the second portrays the city in ruins and the character as a superhero. I intend for this program to make a statement about how volatile our lives & world are.

Minimal Viable Outcome:
- At the very least, I want the character explore the city smoothly. If push comes to shove, I can leave out the commentary aspect of my project. The most important thing is to make sure my code allows for the background to move and the character to be animated.
